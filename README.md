# О проекте
## Что это и зачем?
`SecondSprintExam` - Распределённый вычислитель арифметических выражений.  
**Простыми словами - калькулятор**.  
Выполняет базовые математические вычисления принимая на вход строку с выражением.
_P.S калькулятор имитирует долгое вычисление мат. операций. Время требуемое для их выполнений прописаны в **Переменных среды**. [Подробная информация будет ниже](#Переменные-среды)_

## Поддерживаемые функции
Сервис калькулятор поддерживает базовые математические операции: +, -, *, / (сложение, вычитание, умножение и деление)  
А также операторы приоритизации: ( и )

# Как запустить
## Установка компонентов
### Устанавливаем Git
- __Windows__. Скачайте [Git для Windows](https://git-scm.com/download/win), запустите exe-файл, следуйте инструкциям.
- __macOS__. Скачайте [Git для macOS](https://sourceforge.net/projects/git-osx-installer/) и запустите dmg-файл. Если он не запускается, зайдите в Системные настройки — Безопасность и нажмите кнопку Open anyway (Всё равно открыть).
- __Linux__. Установите Git через встроенный менеджер пакетов. Если у вас Ubuntu, используйте команду sudo apt-get install git. Команды для других дистрибутивов можно посмотреть [здесь](https://git-scm.com/download/linux).

### Устанавливаем Go
Проект написан на языке Go(GoLang), для запуска сервера вам необходимо будет установить его:

Перейдите на официальный сайт и следуйте инструкциям: [ссылка](https://go.dev/doc/install)

### Клонируем репозиторий
Откройте командную консоль и вставьте команду:

`git clone https://github.com/SanyaDr/SecondSprintExam.git`

## Запуск сервера
> [!Caution]
> Если для тестирования вы используете систему Windows, настоятельно рекомендую использовать консоль PowerShell, так как возникают проблемы с кавычками у стандартной командной строки Windows

Далее, вам необходимо открыть в консоли место расположения проекта.  
В моем случае это: `C:\Users\mrdro\SecondSprintExam`, следовательно используйте команду  
`cd C:\Users\User\SecondSprintExam`
> Не забудьте изменить User на имя пользователя вашего ПК

Запустите сервер командой:
`go run cmd/main.go`

Если всё прошло успешно, вы увидите в консоли **время запуска** и **порт** на котором запущен сервер. По умолчанию сервер запускается на порту _8080_
> [!TIP]
> Вы можете [изменить порт запуска](#О-файле-конфигурации) в файле `config/config.go`  
> За это отвечает константа `DefaultLaunchPort`

## Использование калькулятора
Всего калькулятор обрабатывает 3 endpoint'а:
- `/api/v1/calculate` - Принимает новые выражения для вычисления. Принимает только POST запросы! [_описание_](#Как-отправить-новое-выражение)
- `/api/v1/expressions` - Возвращает список всех выражений которые были отправлены на сервер. По этому адресу можете узнать состояние вычисления всех ([Или одного конкретного](#Как-получить-результат-конкретного-выражения))отправленных выражений, а их также результаты [_описание_](#Как-получить-результаты-вычислений)
- `/internal/task` - Используется самим калькулятором для нужд самого калькулятора. Возвращает, принимает и обновляет статусы задач для вычисления. [_описание_](#О-`/internal/task`)

Итак, как вы можете взаимодействовать с калькулятором?

### Как отправить новое выражение
`/api/v1/calculate` - Является основным endpoint'ом, через него вы можете отправить калькулятору новое выражение в _JSON_ формате:    
Однако, если вы попробуете открыть его через обычный браузер `http://localhost:8080/api/v1/calculate`, то вы получите ответ с текстом ___Method is not allowed___.

Сервер принимает только POST запросы. [Ниже вы увидите варианты](#Как-отправлять-запросы) того как вы можете их отправить.

### Как получить результаты вычислений
`/api/v1/expressions` - Позволяет получить историю всех вычислений с момента запуска сервера.
> [!TIP]
> История вычислений не записывается в файл, поэтому после перезапуска сервера, отправленные ранее выражения не сохранятся

`http://localhost:8080/api/v1/expressions` - ожидает GET метод, и вернет выражения в формате
```
{
    "expressions": [
        {
            "id": <идентификатор выражения>,
            "status": <статус вычисления выражения>,
            "result": <результат выражения>
        },
        {
            "id": <идентификатор выражения>,
            "status": <статус вычисления выражения>,
            "result": <результат выражения>
        }
    ]
}
```
**Возвращаемые коды**:
- _200_ - Успешно возвращен список выражений
- _500_ - Ошибка на стороне сервера

### Как получить результат конкретного выражения
Сделать это вы можете обратившись к нему по его iD. Обратитесь по тому же адресу, но с ключом Id:
`http://localhost:8080/api/v1/expressions?Id=1`

Вы получите ответ в формате  
```
{
    "expression":
        {
            "id": <идентификатор выражения>,
            "status": <статус вычисления выражения>,
            "result": <результат выражения>
        }
}
```
Возвращаемые коды:
- _200_ - Успешно получено выражение
- _404_ - Выражение не найдено
- _500_ - Ошибка на стороне сервера

<a name="about-internal-task"></a>
### О /internal/task
`/internal/task` endpoint предназначенный для калькулятора. Для пользователя он не имеет практического смысла.  
Калькулятор, обращаясь к этому endpoint'у:
- Получает (GET метод) новое выражение и отправляет его Агенту для вычисления
- Обновляет (POST метод) статус решенного Агентом выражения  

## Как отправлять запросы
[Отправка нового выражения](#Как-отправить-новое-выражение) поддерживает только POST запросы. Ниже приводим способы отправки этих запросов

### Через консоль
Использование _curl_

Для отправки запроса введите в консоль команду:

- Для стандартной консоли Windows:

`curl localhost:8080/api/v1/calculate --header Content-Type:application/json --data {"""expression""":"""2+2"""}`
- Для PowerShell и других:

`curl 'localhost:8080/api/v1/calculate' --data '{"expression": "2+2"}'`

Вместо _2+2_ впишите своё выражение которое хотите посчитать

### Через Postman
Postman - Сервис для создания, тестирования, документирования, публикации и обслуживания API.

Скачать его вы сможете на [официальном сайте](https://www.postman.com/). Для тестирования вам потребуется скачать Postman Agent, так как тестировать вы будете на локальной машине.

#### Как пользоваться Postman
![image](https://github.com/user-attachments/assets/a018e5be-a09f-4684-99b0-4e68b6af517d)
Вы видите главный экран Postman. В верхней части вы увидите вкладки, как в браузере. Создайте новую вкладку.

![image](https://github.com/user-attachments/assets/597479bd-c2aa-4f88-b1f0-c7a06e07fd8a)
Заполните необходимые поля, как показано на скриншоте.
- Выбран POST запрос
- В адресной ссылке введено: `http://localhost:8080/api/v1/calculate`
- Во вкладке _Body_ выбран режим _raw_ типа JSON
- В текстовом редакторе написан код формата:
`
{
"expression": "2+2*2"
}
`

# Настройка

## О файле конфигурации
В директории `"SecondSprintExam/config"` расположен файл конфигурации _config.go_  
Он содержит константы по умолчанию для запуска сервера:
- **_DefaultLaunchPort_** - Порт запуска. По умолчанию стоит :8080
- **_CheckNewExpression_Timeout_** - timeout для повторного обращения к Оркестратору (указывается в секундах)

## Переменные среды
Эта реализация калькулятора имитирует долгое выполнение операций. Перед тем как выполнить простую операцию, вызывается `<-Time.After(your_time)`, чтобы поставить вычисление на паузу на определенное время. Это время указывается в переменных среды, отдельно для каждой операции.

### Используемые переменные
Данные о переменных также расположены в файле _config.go_ в дериктории `"SecondSprintExam/config"`
Там мы найдем информацию о:
- Названиях переменных, например: `time_addition_name = "TIME_ADDITION_MS"` - _Время выполнения операции сложения в миллисекундах_
- Их значения по умолчанию, если такие переменные не существуют: `stockTimeExecution = 10` - _Время выполнение операции по умолчанию_

### Что если переменные не указаны
Во время запуска, сервер ищет переменные среды по их имени указанных в _config.go_  
Если переменная отсутствует или значение указано некорректно, будет использовано значение по умолчанию `stockTimeExecution` и `stockComputingPower`, по умолчанию указано значение 10 (в миллисекундах) и 3 соответственно.

# Возвращаемые ошибки и коды
_200_ - Ответ успешно получен, ошибок нет  
_404_ - Выражение не найдено  
_422_ - Ошибка пользователя, например выражение введено с ошибкой  
_500_ - Ошибка на стороне сервера  

# Справка по работе калькулятора
О _**ComputingPower**_  
Вы можете отправить несколько Post запросов подряд (`/api/v1/calculate`), для вычисления которых требуется время. Для сокращения времени, калькулятор может вычислять несколько выражений одновременно.  
Количество одновременно вычисляемых выражений задаётся параметром _ComputingPower_ в [Переменных среды](#Переменные-среды) и [_Config.go_](#О-файле-конфигурации)
